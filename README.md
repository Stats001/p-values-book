# How to Get P-Values Less Than 0.05 in Biological Research

*Practical examples of how to increase power, reduce sample size, and choose better statistics tests*

**By Michael Walker**

## About this book

This book provides practical guidance for biological researchers who want to get the most out of their statistical analyses. It covers:

- Using multiple regression and ANOVA instead of t-tests
- Power and sample size calculations
- Reducing unexplained variability
- Wilcoxon and Kruskal-Wallis rank tests for non-normal data
- Robust statistical methods
- Interaction effects
- Correlated variables
- CMH tests for ordered categories
- Factorial and fractional factorial experiment design
- Multiple hypothesis testing
- And more!
